# AtaMaster Pro v3 - Business Intelligence Edition

AtaMaster Pro é uma solução robusta para gestão de atas de reuniões corporativas, focada em produtividade e acompanhamento de pendências.

## Funcionalidades
- **Ata Viva**: Carrega automaticamente tarefas em aberto de reuniões anteriores do mesmo grupo.
- **Alertas P3**: Alerta visual para itens que atingiram o terceiro prazo de acompanhamento.
- **PDF Fusion**: Gera a ata em PDF e permite mesclar com outros documentos anexos.
- **Dashboard**: Visão executiva de KPIs e pendências críticas.
- **Gestão de Grupos**: Organize suas atas por contexto ou departamento.

## Requisitos
- Python 3.10+
- Bibliotecas listadas em `BUILD.md`
